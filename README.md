## What it does
Twelve one-line office jokes were drafted and scored on the brief's five axes — office joke first, punch sharpness, instant clarity, freshness, tight wording — and the strongest one is written to `/output/entry.txt`, the same bytes on every run.
## The winning line
> HR's wellness survey asked what would improve my mental health; I wrote 'fewer wellness surveys,' so they sent me a survey asking about my answer.
## How to run
Run with `python3 ./main.py`.
